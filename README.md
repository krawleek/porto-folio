# Porto-folio

Адаптивное портфолио Елены Юнг по Figma, на Vite + HTML/CSS/JavaScript.

Страница About: `/about/`, макет `325:275`. Одна закреплённая композиция с тремя состояниями скролла и шестью карточками, которые собираются в интерактивный веер. На desktop карточки открывают модальное окно, на мобильном — bottom sheet с внутренним скроллом и закрытием свайпом вниз. Также работают Close, клик по фону и Esc; фокус и позиция страницы восстанавливаются. При reduced motion всё содержимое доступно без закрепления и анимации. Поддержаны RU/ENG; английские тексты без отдельного перевода в макете переведены из русского. Изображения: `public/assets/about`, источники: `design/about-assets.json`. Проверка: `node tests/about.mjs`.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` — сборка в `dist`. `npm run preview` — просмотр сборки.
`npm test` — браузерные проверки через установленный Google Chrome; предварительно запустить сервер на порту 5173.

## Поведение

Карточки складываются при скролле; перекрытые слои плавно скрываются полностью. При reduced motion анимации отключаются. CTA-карточка реагирует на курсор; на touch-устройствах наклон отключён. Кнопки почты копируют `krawleek@yandex.ru`, при недоступном Clipboard API открывают почтовое приложение. Резюме и социальные ссылки взяты из аннотаций Figma.

NDA-интерфейс использует пароль из аннотаций Figma и `sessionStorage.ndaAccess`; на десктопе поле возникает у точки клика, на мобильном открывается нижняя панель. Это клиентский интерфейс доступа, а не серверная защита конфиденциальных материалов. Конфиденциальные материалы в проект не добавлены.

Кейс НСПК доступен по `/cases/nspk/` и подключён к общему NDA-доступу. Прямой переход без доступа возвращает на главную и открывает поле пароля для НСПК. Остальные кейсы пока открывают краткое описание. Пункт «Обо мне» ведёт к вводному блоку главной.

Страница НСПК собрана по Figma `111:8727`. Карусель из трёх слайдов переключается каждые 5 секунд, останавливается при наведении, фокусе, скрытии вкладки и уходе секции с экрана. Есть ручное переключение и свайпы; при reduced motion автопрокрутка изначально выключена. Два независимых сравнения до/после поддерживают мышь, касания и клавиатуру. Проверка: `node tests/nspk.mjs` при запущенном сервере на порту 5173. Vite собирает главную и страницу кейса как отдельные HTML-входы.

Мобильный хедер закреплён и раскрывается по кнопке. Закрывается по кнопке, клику вне меню, выбору раздела и Escape. RU/ENG использует Nina CTT, пересобранный из TTF в WOFF2. Удержание нижней карточки раскручивает её, после отпускания вращение плавно замедляется.

`node tests/updates.mjs` проверяет меню, шрифт, обложки, скрытие стопки и вращение.

Кейс Альфа-Банка: `/cases/alfa/` (публичный). Макет `26:10371`, локальные изображения — `public/assets/alfa`, исходные ссылки — `design/alfa-assets.json`. Две sticky-секции по три состояния следуют аннотациям Figma; при reduced motion все состояния доступны без закрепления. RU/ENG переводит текст страницы; текст внутри изображений остаётся исходным.

Два видео подключены напрямую из присланных MP4: `public/videos/alf-visualisation.mp4` и `public/videos/alf-2.mp4`. Native video: autoplay, muted, loop, playsinline, без controls. Второе видео загружается при приближении к секции; вне viewport воспроизведение приостанавливается. При reduced motion или запрете autoplay доступна кнопка запуска. Vimeo не используется: соединение в тестовой среде блокировалось сервисом.

Кейс ВТБ НПФ: `/cases/vtb/`, общий пароль кейсов и доступ в текущей вкладке. Макет `113:4710`, карусель `326:3839`, локальные изображения — `public/assets/vtb`. Карусель меняет слайд каждые 5 секунд; три sticky-секции содержат по два состояния. Общие реализации карусели и смены экранов находятся в `case-carousel.js` и `case-showcase.js`. RU/ENG переводит текст, изображения сохраняют исходный язык. Следующий кейс ведёт на Альфа-Банк. Проверка: `node tests/vtb.mjs`.

Кейс WASD: `/cases/wasd/`, макет `276:25534`, общий пароль. Изображения сохранены в `public/assets/wasd`, исходные ссылки — `design/wasd-assets.json`. Две sticky-секции: персонализация (2 состояния) и XP/квесты (3 состояния, включая смену заголовка). На reduced motion все пять состояний доступны без закрепления. RU/ENG, переход к НСПК, нулевой мобильный отступ перед футером. Проверка: `node tests/wasd.mjs`.
