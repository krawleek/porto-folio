# Porto-folio

Адаптивное портфолио Елены Юнг по Figma, на Vite + HTML/CSS/JavaScript.

Страница About: `/about/`, макет `325:275`. Одна закреплённая композиция с тремя состояниями скролла и шестью карточками, которые собираются в интерактивный веер. На desktop карточки открывают модальное окно, на мобильном — bottom sheet с внутренним скроллом и закрытием свайпом вниз. Также работают Close, клик по фону и Esc; фокус и позиция страницы восстанавливаются. При reduced motion всё содержимое доступно без закрепления и анимации. Поддержаны RU/ENG; английские тексты без отдельного перевода в макете переведены из русского. Изображения: `public/assets/about`, источники: `design/about-assets.json`. Проверка: `node tests/about.mjs`.

## Запуск

```sh
npm install
npm run dev
```

`npm run build` — сборка в `dist`. `npm run preview` — просмотр сборки.
`npm test` — браузерные проверки через установленный Google Chrome; предварительно запустить сервер на порту 5173.

## Поведение

Карточки складываются при скролле; перекрытые слои плавно скрываются полностью. При reduced motion анимации отключаются. CTA-карточка реагирует на курсор; на touch-устройствах наклон отключён. Кнопки почты копируют `krawleek@yandex.ru`, при недоступном Clipboard API открывают почтовое приложение. Резюме и социальные ссылки взяты из аннотаций Figma.

NDA-интерфейс использует пароль из аннотаций Figma и `sessionStorage.ndaAccess`; на десктопе поле возникает у точки клика, на мобильном открывается нижняя панель. Это клиентский интерфейс доступа, а не серверная защита конфиденциальных материалов. Конфиденциальные материалы в проект не добавлены.

Кейс НСПК доступен по `/cases/nspk/` и подключён к общему NDA-доступу. Прямой переход без доступа возвращает на главную и открывает поле пароля для НСПК. Остальные кейсы пока открывают краткое описание. Пункт «Обо мне» ведёт к вводному блоку главной.

Страница НСПК собрана по Figma `111:8727`. Карусель из трёх слайдов переключается каждые 5 секунд, останавливается при наведении, фокусе, скрытии вкладки и уходе секции с экрана. Есть ручное переключение и свайпы; при reduced motion автопрокрутка изначально выключена. Два независимых сравнения до/после поддерживают мышь, касания и клавиатуру. Проверка: `node tests/nspk.mjs` при запущенном сервере на порту 5173. Vite собирает главную и страницу кейса как отдельные HTML-входы.

Мобильный хедер закреплён и раскрывается по кнопке. Закрывается по кнопке, клику вне меню, выбору раздела и Escape. RU/ENG использует Nina CTT, пересобранный из TTF в WOFF2. Удержание нижней карточки раскручивает её, после отпускания вращение плавно замедляется.

`node tests/updates.mjs` проверяет меню, шрифт, обложки, скрытие стопки и вращение.

Кейс Альфа-Банка: `/cases/alfa/` (публичный). Макет `26:10371`, локальные изображения — `public/assets/alfa`, исходные ссылки — `design/alfa-assets.json`. Две sticky-секции по три состояния следуют аннотациям Figma; при reduced motion все состояния доступны без закрепления. RU/ENG переводит текст страницы; текст внутри изображений остаётся исходным.

Два видео подключены напрямую из присланных MP4: `public/videos/alf-visualisation.mp4` и `public/videos/alf-2.mp4`. Native video: autoplay, muted, loop, playsinline, без controls. Оба видео загружаются при приближении к секции; вне viewport воспроизведение приостанавливается. При reduced motion или запрете autoplay доступна кнопка запуска. Vimeo не используется: соединение в тестовой среде блокировалось сервисом.

Кейс ВТБ НПФ: `/cases/vtb/`, публичный, без пароля. Макет `113:4710`, карусель `326:3839`, локальные изображения — `public/assets/vtb`. Карусель меняет слайд каждые 5 секунд; три sticky-секции содержат по два состояния. Общие реализации карусели и смены экранов находятся в `case-carousel.js` и `case-showcase.js`. RU/ENG переводит текст, изображения сохраняют исходный язык. Следующий кейс ведёт на Альфа-Банк. Проверка: `node tests/vtb.mjs`.

Кейс WASD: `/cases/wasd/`, макет `276:25534`, публичный, без пароля. Изображения сохранены в `public/assets/wasd`, исходные ссылки — `design/wasd-assets.json`. Две sticky-секции: персонализация (2 состояния) и XP/квесты (3 состояния, включая смену заголовка). На reduced motion все пять состояний доступны без закрепления. RU/ENG, переход к НСПК, нулевой мобильный отступ перед футером. Проверка: `node tests/wasd.mjs`.

Прелоадер показывается один раз за сессию вкладки, включая прямой вход в кейс. Отметка сохраняется до загрузки ресурсов, поэтому прерванная загрузка, обновление, переключение языка и последующие переходы не запускают его повторно. При недоступном sessionStorage прелоадер пропускается.

Обновления кейсов: первая иллюстрация НСПК RU — Figma `112:3928`; баннер НСПК в WASD RU/EN — `326:3959` / `512:4526`; баннер Альфа-Банка в ВТБ RU/EN — `238:3629` / `514:12898`. Локальные изображения: `public/assets/case-refresh`. Для баннера Альфа-Банка используются обновлённые изображения телефона из Figma; превью второго видео — узел `111:3881`, оно остаётся до первого кадра и возвращается при ожидании или ошибке видео. Межстрочные интервалы основного текста увеличены до 20/26, 24/30 и 32/38; крупные заголовки и ритм разделов 72/48 сохранены. Проверка: `node tests/case-refinement.mjs` (по умолчанию localhost:5175, можно задать BASE_URL).


## Доставка изображений и видео

На главных RU/EN и в кейсах Alfa, WASD, NSPK и VTB PNG/JPEG подключены через `srcset` и `sizes`. В `public/assets/responsive` лежат WebP без сжатия с потерями: уменьшенные варианты под размер блока и DPR, а также вариант исходного разрешения. Размеры учитывают увеличение изображений внутри обрезанных обложек. Если исходный файл экономнее WebP, он сохраняется в наборе; более тяжёлые кандидаты меньшего разрешения исключены. Оригиналы не удалены и не перезаписаны. Обложки четырёх кейсов на главных RU/EN заново выгружены из Figma 4 октября; исходные PNG сохранены в `public/assets/main-refresh`, адаптивные WebP — в `public/assets/responsive`. Остальные изображения главной не перекодировались.

Неактивные состояния sticky-секций и каруселей используют `data-src`/`data-srcset`; `src/image-loading.js` подключает их по запросу. Следующее состояние подгружается заранее, переключение ожидает декодирование изображения. В reduced motion статические состояния загружаются около своей позиции на странице. Изображения карточек главной используют native lazy loading.

У обоих видео Alfa `preload="none"` и отложенный `data-src`. Адаптивная картинка-превью заменяет отдельный native poster, чтобы браузер не скачивал два изображения. Превью остаётся до первого кадра и при ожидании/ошибке. MP4 сохранены без перекодирования; их полный вес при просмотре обоих роликов не уменьшился.

`design/image-delivery.json` содержит исходные размеры и точный вес каждого кандидата. `scripts/optimize-images.mjs` — первоначальная миграция (повторный запуск при существующем manifest заблокирован); `scripts/finalize-image-delivery.mjs` уточняет кандидаты и подключения на основе manifest. Это генераторы медиа, а не команды сборки сайта. При обновлении исходной картинки нужен новый набор производных: нельзя просто перезаписать оригинал и ожидать обновления хешированных файлов.

После этих изменений build, тесты, preview, Lighthouse и браузер не запускались. Размеры файлов не являются замером реального сетевого трафика: выбор кандидатов и момент lazy loading зависят от viewport, DPR и браузера. Общий размер каталога public увеличивается из-за сохранения оригиналов и нескольких разрешений, но пользователь получает только выбранные варианты.

Обновление обложек главной: фреймы `368:4168` (RU) и `466:6246` (EN). ВТБ повторно выгружен после изменения макета: RU `394:11095`, EN `466:7935`; ширина изображения в обеих карточках 155,26%, положение и высота отдельно для каждого языка. Генератор `scripts/refresh-home-images.mjs` сохраняет исходники, создаёт lossless WebP и обновляет `srcset`/`sizes` с учётом кадрирования, ширины карточек и DPR. Сборка и runtime-проверки после этого обновления не запускались.

ВТБ и WASD открываются без проверки `ndaAccess` в RU/EN, включая прямые ссылки. На главной у этих карточек удалён NDA; общий `cutoutCards` выводит ту же стрелку и вырез, что у Alfa. Ссылки в футерах ведут непосредственно в кейсы.
